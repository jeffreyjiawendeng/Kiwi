# Keyboard shortcuts

Press **?** anywhere you are not typing to see this list in the application.

## Everywhere

| Keys         | Does                                                      |
| ------------ | --------------------------------------------------------- |
| Ctrl+K       | Open the command centre and search                        |
| Ctrl+P       | The same list                                             |
| Ctrl+Shift+P | The same list, in command mode                            |
| Ctrl+Shift+I | Quick Capture                                             |
| Ctrl+B       | Fold the rail to monograms, or unfold it                  |
| Ctrl+\       | Keep the details on this object while you look at another |
| F6           | Move between the rail, the page, and the dock             |
| Escape       | Close what is open, or clear the filter                   |
| ?            | Show the shortcut reference                               |

## Documents

| Keys           | Does                                           |
| -------------- | ---------------------------------------------- |
| Ctrl+W         | Close the open document tab                    |
| Ctrl+Tab       | Go to the next document tab                    |
| Ctrl+F         | Find in this document                          |
| Ctrl+H         | Find and replace, on the same bar              |
| Ctrl+S         | Save now, though everything saves itself       |
| Ctrl+Shift+V   | Paste without formatting                       |
| Ctrl+Shift+[   | Fold the section at the caret, in LaTeX source |
| Ctrl+Z, Ctrl+Y | Undo and redo                                  |

## Lists

| Keys      | Does                           |
| --------- | ------------------------------ |
| Ctrl+A    | Select everything visible      |
| Space     | Tick or untick the focused row |
| Enter     | Open the focused row           |
| Shift+F10 | Open the row's menu            |
