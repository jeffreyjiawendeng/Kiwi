# Kiwi user guide

Kiwi keeps a research project in one place: the papers, what you marked in them, your notes, the
claims you are weighing, the tasks, and the manuscript. Everything is a readable file in a folder
you choose, and a project is the set of those things that belong together.

![The dashboard of a literature review project](../assets/dashboard.png)

The pictures in this guide show an invented project, with invented papers and people.

## How Kiwi is arranged

- A **workspace** is a folder on your computer. It holds any number of projects and everything in
  them. Share a workspace and the people you invite see the same folder, kept in step through the
  account service.
- A **project** is one piece of work: a review, a thesis chapter, a reading group. It has a
  research question, a protocol, and its own Library, Notes, Claims, Tasks, and Manuscript.
- **Objects** are what a project is made of: papers, files, notes, claims, tasks, and the
  manuscript. Every object has a version history, can carry tags and comments, and can be linked
  to any other.

## The pages

| Page                | What it is for                                                                              |
| ------------------- | ------------------------------------------------------------------------------------------- |
| Dashboard           | Where the project stands: counts, your work, what needs attention, and what happened lately |
| Inbox               | Thoughts captured in passing, waiting to be filed                                           |
| Library             | The papers and files, with their references, tags, and read state                           |
| Reader              | PDFs open for reading and marking up                                                        |
| Notes               | Notes, written alone or together                                                            |
| Claims & Evidence   | What you are prepared to say, and what supports or contradicts it                           |
| Manuscript          | The piece of writing the project produces                                                   |
| Tasks               | Who is doing what, by when                                                                  |
| Question & Protocol | The research question, hypotheses, criteria, and extraction schema                          |
| Search & Import     | Search across the workspace                                                                 |
| Bibliography        | The references cited in the manuscript, in the project's citation style                     |
| Review              | Every comment thread in the project, by what it is about                                    |
| History             | Every change anybody made, with filters                                                     |
| Members             | Who is in the workspace, their roles, and invitations                                       |
| Settings            | The project's name, description, type, pages, citation style, and sensitivity               |
| Trash               | What was deleted, until it is restored or cleaned up                                        |

Screening, Extraction Table, Codebook, Data, Analysis, Results, Export & Release, and Graph are
listed for projects whose type turns them on, but in this version each opens as a placeholder that
says so.
